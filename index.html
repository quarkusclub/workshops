Integrando aplicações Java com LLMs, production grade

Integrating Java applications with LLMs, production grade

Chamar um LLM a partir do Java é fácil, mas isso não é uma aplicação pronta para produção: falta contexto real nas respostas, controle sobre o que o modelo pode fazer e visibilidade quando algo sai errado. Aqui você integra um LLM ao Quarkus com LangChain4j e evolui essa integração passo a passo. Roda na API gratuita da NVIDIA.

Calling an LLM from Java is easy, but that is not an application ready for production: it lacks real context in its answers, control over what the model may do, and visibility when something goes wrong. Here you integrate an LLM into Quarkus with LangChain4j and grow that integration step by step. Runs on the free NVIDIA API.

Prepare sua máquinaPrepare your machine

Específico do workshop de LangChain4j. Rode antes do workshop, na máquina que você vai usar. O script verifica seu ambiente, baixa o que a rede do evento não vai dar conta, e termina com um health check dizendo se você está pronto.

Specific to the LangChain4j workshop. Run it before the workshop, on the machine you will use. It verifies your setup, warms the caches that venue wifi cannot handle, and ends with a health check that tells you whether you are ready.

Linux / macOS
curl -fsSL https://quarkusclub.github.io/workshops/langchain4j/scripts/prepare.sh | bash
Windows PowerShell
irm https://quarkusclub.github.io/workshops/langchain4j/scripts/prepare.ps1 | iex

Os scripts não instalam nada no sistema e não pedem elevação. Para ler antes de executar, baixe com -o ou -OutFile primeiro: é um bom hábito com qualquer script vindo da internet. O código está em langchain4j/scripts.

The scripts install nothing system-wide and never ask for elevation. To read before running, download with -o or -OutFile first: a good habit with any script from the internet. The source lives in langchain4j/scripts.
